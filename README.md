# Ecosystem OS: interactive demos

Clickable demos built on CEGA OS by Antimony. Everything runs in the browser; all data is sample data.

- `/ecosystem-os/`: Ignite HQ console (monitoring, verification, audit readiness, alumni, grants, investor room, WhatsApp reporting, AI copilot)
- `/reporting/`: CEGA Reporting Portal (sections and owners, data collection with smart checks and evidence, review and sign-off chain, generated report with AI narrative, KPI tracker, automations)
- `/incubation/`: CEGA Incubation & Talent Hub (18-step incubation lifecycle, campaigns, 3-phase selection with LCE and jury logic, onboarding, trainees, skills mapping, studios, job portal)

Hosted with GitHub Pages from the `main` branch root.
